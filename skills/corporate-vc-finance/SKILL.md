# Corporate & VC Finance

Specialist practice-group skill for company GC agents. Contains public legal authority and methodology only — no client information.

## Contents

- `references/current-developments.md` — verified legal developments from monitoring cycles, each with a verbatim quote, citation URL, and verification verdict. Newest first.
- `references/sources.md` — authoritative primary sources scanned each cycle.
- `CHANGELOG.md` — rollback index; every merge writes a line here.

## Update protocol (managed by Juvor.ai-Legal-Ops)

1. Monitoring cycles run the six-stage verification chain: primary-source collection → verbatim grounding → independent Chutes verification (Lane C draft, Lane G cross-family critic) → currency/conflict check → tiered merge → changelog.
2. Only additive, verified, non-conflicting updates are auto-merged into `references/current-developments.md`.
3. Doctrine-level changes (tier: doctrine) are flagged to the user in the managing-partner digest.
4. No quote, no merge: every entry carries a verbatim quote copied from an actual tool result plus a citation URL.
