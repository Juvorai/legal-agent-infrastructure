# Sector-Specific Fast Reference

Load when the company sector is known (crypto, AI, fintech, insurtech) or the user asks for a GC checklist / launch readiness review.

---

### Crypto / Digital Assets — GC Checklist

| Area | Key Action | Authority |
|------|-----------|-----------|
| Token classification | Apply 5-category SEC framework (commodity, security, stablecoin, collectible, tool) | SEC Release No. 33-11412 (2026)[^5] |
| Stablecoin issuance | GENIUS Act compliance: reserve backing, AML, OCC/Fed/state issuer license | Public Law 119-27 (2025)[^11] |
| Exchange/broker registration | Provisional registration under CLARITY Act (pending) | CLARITY Act (2025)[^13] |
| DeFi safe harbor | Non-custodial protocol participants (devs, validators) exempt from registration | CLARITY Act § DeFi provisions[^13] |
| EU operations | MiCA CASP license; whitepaper for token issuance | MiCA Art. 63+ (fully effective Dec 2024)[^28] |
| Insider token sales | Graduated CLARITY Act restrictions; lockup analysis | CLARITY Act insider provisions[^13] |
| Private litigation defense | Howey analysis + disclosure adequacy defense | SEC v. W.J. Howey Co. + Release 33-11412[^26] |

### AI Startup — GC Checklist

| Area | Key Action | Authority |
|------|-----------|-----------|
| AI governance framework | Inventory → classify → policy → oversight committee → vendor mgmt | NIST AI RMF; Bloomberg Law guidance[^30] |
| EU AI Act compliance | Identify risk tier; GPAI obligations (Aug 2025); core obligations (Aug 2026) | EU AI Act (2024/1689)[^33] |
| Training data rights | License agreements; fair use analysis; vendor IP warranties | Copyright Act; pending AI copyright litigation[^23] |
| Trade secret protection | Audit AI assets; update IP assignments; vendor clauses | DTSA; UTSA; USPTO guidance[^23][^42] |
| AI-generated IP | Ensure human authorship; document human creative control | USPTO AI Inventorship Guidance (2024) |
| Employment/hiring AI | EEO compliance; adverse action notices for AI credit/hiring | CFPB; EEOC guidance[^30] |

### Fintech — GC Checklist

| Area | Key Action | Authority |
|------|-----------|-----------|
| Money transmission | 48-state license analysis + NMLS filing | State banking departments |
| Lending | TILA, ECOA, FCRA compliance + state usury | 15 USC §§ 1601, 1691; FCRA |
| Open banking | Section 1033 CFPB Final Rule compliance; API standards | 12 CFR Part 1033 (2024) |
| BaaS partnerships | Risk allocation; charter responsibility documentation | OCC/FDIC BaaS guidance |
| AML program | FinCEN MSB registration; KYC/CIP; SAR/CTR | 31 CFR Part 1010 |

### Insurtech — GC Checklist

| Area | Key Action | Authority |
|------|-----------|-----------|
| Operating model | Carrier vs. MGA vs. vendor — licensing obligations differ fundamentally | State insurance codes[^37] |
| AI underwriting | NAIC Model Bulletin + NY DFS Circular Letter 2024-7 compliance | NAIC (2023); NYDFS (2024)[^37] |
| Algorithmic fairness | Document model inputs; audit for proxy discrimination | NY DFS Circular Letter 2024-7[^37] |
| Rate/form filing | State approval before product launch | State insurance departments |
| Embedded insurance | Delegated authority agreements; binding authority limits | State MGA statutes[^37] |
| Data privacy | State comprehensive privacy laws + HIPAA (if applicable) | CCPA/CPRA; HIPAA |
