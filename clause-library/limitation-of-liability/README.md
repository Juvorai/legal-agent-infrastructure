# Limitation of Liability Clause Library

Market-standard limitation of liability language extracted from SEC EDGAR EX-10 material contract filings.

## Usage

These clauses are **market-practice evidence only**, never legal authority. Use them to:
- Benchmark proposed contract language against market standards
- Identify common drafting patterns and variations
- Support negotiation positions with precedent

## Sources

All clauses are extracted from publicly filed SEC exhibits (8-K filings with EX-10 attachments).
Source metadata (entity, accession number, filing date) is included with each clause.

## Clause Format

Each entry contains:
- `source_entity`: Company that filed the contract
- `source_accession`: SEC accession number for the filing
- `source_exhibit`: Exhibit filename
- `filed_date`: Date the contract was filed with SEC
- `clause_text`: The extracted clause language
